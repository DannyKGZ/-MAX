# ⚽ max-football-bot — бот записи на футбол для мессенджера MAX

**Готовый бот для мессенджера MAX для организации любительского футбола:** автоматическая запись на игру по расписанию, основа на 10 мест с резервом, голосование за MVP с накопительным рейтингом, делёжка на команды, учёт оплаты с проверкой PDF-чеков и поддержка нескольких чатов одновременно.

> Работает напрямую с официальным REST API MAX (`https://platform-api2.max.ru`) — без сторонних SDK. Node.js + TypeScript + SQLite, сквозные тесты, деплой в один скрипт.

## ✨ Возможности

### Запись на игру
- 📅 **Автопубликация** записи по расписанию (по умолчанию пн/пт в 9:00) — настраивается через `/расписание` или `/игры`.
- 👥 **Основа на 10 мест + резерв** с автоматическим подъёмом резервиста при уходе игрока из основы.
- ➕ **Команды `+` / `+Имя` / `+Имя +Имя`** — запись себя и до 5 друзей одним сообщением.
- ➖ **`-` / `-Имя`** — удаление только своих записей, без переспроса.
- 🔒 **Автозакрытие** записи в момент начала игры.

### Голосование и рейтинг MVP
- 🏆 **Голосование за MVP** — запускается вручную (`/голосование`) или автоматически после игры.
- 📊 **Прогресс-бар и счёт прямо на кнопках**, открытый лог «кто → за кого», 🔴/✅ у голосующих.
- 🥇 **До 3 MVP** при ничьей, случайные поздравления из 30 заготовок, автоочистка чата.
- 📈 **Рейтинг в трёх срезах:** сезон, игровой год, всё время. Автопереключение сезонов, легенда года 1 декабря.

### Роли и команды
- 🎖 **Легенда** (всегда 1-й в записи, ровно год) и 👕 **манишкаНосец** (всегда 2-й) — назначаются админом.
- ⚽ **Делёжка на команды** — капитаны от админа, выбор игроков по очереди кнопками.

### Оплата
- 💰 **Напоминания по часам** (−3…−1 ч и +1…+2 ч) с упоминанием каждого записавшего и его суммой.
- 📄 **Проверка PDF-чеков:** бот читает получателя и сумму, спорные случаи — на ручную проверку.
- 📋 **`/должники`** с разбивкой по месяцам, `/оплатил` для отметки наличных.

### Мультичатность и права
- 🔢 **Несколько чатов одновременно** (`CHAT_IDS=-111,-222`), у каждого свои настройки, расписание, рейтинг и админы.
- 🛡 **Разделение прав:** участники видят только свои команды, админская панель — в личке с ботом.
- 📢 **`/Всем` / `@all`** — объявление с упоминанием всех участников.

### Надёжность
- 💾 **SQLite (WAL)** — всё состояние переживает перезапуск, миграция старых JSON.
- 🚦 **Рейт-лимитер** ≤2 RPS на чат поверх ≤30 RPS суммарно.
- 🧪 **Сквозные тесты** против подставного MAX API.
- 🚀 **Деплой в один скрипт** + systemd с автовосстановлением + бэкапы.

## 🎮 Команды

### Участники
| Команда | Что делает |
|---|---|
| `+` / `+Имя` | записать себя / друга (до 5 имён) |
| `-` / `-Имя` | убрать свою запись / друга |
| `/статус` | актуальна ли запись, основа и резерв, когда следующая |
| `/mvp` | рейтинг MVP за сезон и за всё время |
| `/имя Новое имя` | изменить своё имя в списке |
| `/голос` | показать голосование за MVP |
| `/help` | инструкция в личку |

### Администраторы
| Команда | Что делает |
|---|---|
| `/старт` · `/закрыть` | открыть / закрыть запись |
| `/удалить` · `/переименовать` · `/поменять` | правка списка |
| `/дележка` | деление на команды |
| `/расписание` · `/игры` · `/описание` | расписание и шапка записи |
| `/легенда` · `/манишкаНосец` | роли |
| `/голосование` · `/итоги` | голосование за MVP |
| `/должники` · `/оплатил` · `/оплата` | учёт оплаты |
| `/Всем` · `@all` | объявление с упоминанием всех |
| `/настройки` | панель настроек чата |

Полная шпаргалка команд — в основной документации (доступна по запросу).

## ⚙️ Настройка

Основные переменные в `.env`:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `BOT_TOKEN` | — | токен бота MAX |
| `CHAT_IDS` | — | ID чатов через запятую |
| `MAX_PLAYERS` | `10` | мест в основе |
| `CRON_SCHEDULE` | `0 9 * * 1,5` | когда публиковать запись |
| `UPDATES_MODE` | `webhook` | `webhook` (ПК + туннель) или `polling` (сервер) |
| `DB_FILE` | `./data/bot.db` | база SQLite |
| `TIMEZONE` | `Europe/Moscow` | часовой пояс бота |

## 🧪 Тесты

Бот прогоняется сквозными тестами против подставного MAX API. Покрыты запись, голосование, расписание, панель, рестарт, оплата, `/Всем`, миграция JSON → SQLite. Реальный чат не затрагивается.
